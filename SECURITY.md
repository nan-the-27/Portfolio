# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or privacy issue within this project, please report it responsibly.

### Contact

Please send an email to: **cheang.chamnann@icloud.com**

Please include:
- A description of the issue
- Steps to reproduce or proof of concept
- The potential impact

I will review your report and address any confirmed vulnerabilities as quickly as possible. Please do not open public GitHub issues for security vulnerabilities.
