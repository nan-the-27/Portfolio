# Nan — Photography Portfolio

Personal photography portfolio website showcasing portraits, graduation sessions, architecture, and street photography based in Phnom Penh, Cambodia.

Hosted with GitHub Pages: `https://nan-the-27.github.io/Portfolio/`

## Project Structure

```
├── fonts/          # Self-hosted web typography
├── img/            # Optimized web photography assets (max 2400px, EXIF-stripped)
├── index.html      # Responsive single-page portfolio & enquiry interface
├── code.gs         # Reference Google Apps Script handler for enquiry forms
├── robots.txt      # Search engine crawl directives
├── sitemap.xml     # Search engine sitemap
├── LICENSE         # Copyright and usage terms
└── SECURITY.md     # Security guidelines and PCI DSS architecture
```
